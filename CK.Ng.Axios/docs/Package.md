Provides the default axios instance of an Angular application: the `AxiosPackage` declares the `axios` library (peer
dependency) and adds the `AXIOS` injection token (`InjectionToken<AxiosInstance>`) to the generated `@local/ck-gen`,
provided at the root with `axios.create()`.
See the [README](https://github.com/signature-opensource/CK-TS-Angular/blob/stable/CK.Ng.Axios/README.md).
