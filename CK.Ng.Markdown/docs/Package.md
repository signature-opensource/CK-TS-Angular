Renders Markdown in an Angular application: the `MarkdownPackage` declares the `marked` library and adds the standalone
`MarkdownComponent` (`<ck-markdown [text]="...">`, sanitized by Angular) to the generated `@local/ck-gen`.
See the [README](https://github.com/signature-opensource/CK-TS-Angular/blob/stable/CK.Ng.Markdown/README.md).
