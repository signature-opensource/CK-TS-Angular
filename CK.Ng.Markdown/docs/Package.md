Renders Markdown in an Angular application with the standalone `MarkdownComponent`.

The `MarkdownPackage` declares the `marked` library and adds the `MarkdownComponent` (`<ck-markdown [text]="...">`,
sanitized by Angular) to the generated `@local/ck-gen`.

See the [README](https://github.com/signature-opensource/CK-TS-Angular/blob/stable/CK.Ng.Markdown/README.md).
