# CK-TS-Angular

Angular support of the TypeScript engine: the generated `@local/ck-gen` code integrated in an Angular application,
and the packages that bring Angular features to it.

| Package | Description | Latest stable |
|---------|-------------|---------------|
| [CK.TS.Angular](CK.TS.Angular/README.md) | Supports Angular by enabling the `@local/ck-gen` code to interact with an Angular host application. | [![nuget](https://img.shields.io/nuget/v/CK.TS.Angular.svg?label=CK.TS.Angular)](https://www.nuget.org/packages/CK.TS.Angular/) |
| [CK.TS.Angular.Engine](CK.TS.Angular.Engine) | The engine side: generates and integrates the Angular application, and upgrades it to the engine's Angular major. | [![nuget](https://img.shields.io/nuget/v/CK.TS.Angular.Engine.svg?label=CK.TS.Angular.Engine)](https://www.nuget.org/packages/CK.TS.Angular.Engine/) |
| [CK.Ng.Axios](CK.Ng.Axios) | Imports the axios library and provides the Angular `AXIOS` injection token. | [![nuget](https://img.shields.io/nuget/v/CK.Ng.Axios.svg?label=CK.Ng.Axios)](https://www.nuget.org/packages/CK.Ng.Axios/) |
| [CK.Ng.Localization](CK.Ng.Localization) | Imports "@ngx-translate/core" and adds the automatic translations loader. | [![nuget](https://img.shields.io/nuget/v/CK.Ng.Localization.svg?label=CK.Ng.Localization)](https://www.nuget.org/packages/CK.Ng.Localization/) |
| [CK.Ng.PublicPage](CK.Ng.PublicPage) | The public page: the routed component of the application root. | [![nuget](https://img.shields.io/nuget/v/CK.Ng.PublicPage.svg?label=CK.Ng.PublicPage)](https://www.nuget.org/packages/CK.Ng.PublicPage/) |
| [CK.Ng.Zorro](CK.Ng.Zorro/README.md) | Wraps ng-zorro-antd and provides shared services, styles and utilities. | [![nuget](https://img.shields.io/nuget/v/CK.Ng.Zorro.svg?label=CK.Ng.Zorro)](https://www.nuget.org/packages/CK.Ng.Zorro/) |
| [CK.Ng.AspNet.WebSocketChannel](CK.Ng.AspNet.WebSocketChannel) | Angular support of the single WebSocket channel: provides the one `WSConnection` of the application and opens it during the bootstrap. | [![nuget](https://img.shields.io/nuget/v/CK.Ng.AspNet.WebSocketChannel.svg?label=CK.Ng.AspNet.WebSocketChannel)](https://www.nuget.org/packages/CK.Ng.AspNet.WebSocketChannel/) |
| [CK.Ng.AspNet.Auth](CK.Ng.AspNet.Auth/README.md) | Deprecated: replaced by CK.Ng.Cris.AspNet.Authentication. | |
| [CK.Ng.AspNet.Auth.Basic](CK.Ng.AspNet.Auth.Basic/README.md) | Deprecated: replaced by CK.Ng.Cris.AspNet.Authentication.Basic. | |
